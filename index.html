04合成与升级链

基础手机（3×3 工作台）

四角羊毛（任意颜色）、上下铁锭、左右红石粉、正中钻石块。

十代机型升级路线

I→ II→ III→ IV→ V→ VI→ VII→ VIII→ X→ Pro Max

举报次数随之提升：10 → 20 → 30 → 50 → 50 → 60 → 70 → 80 → 90 → 无限

等级系统（与机型升级是两套）

  • 9 级：背包备 8 个钻石，脚下地面放 1 个信标（代表手机），输入 !level up 检测，消耗 8 钻石升级。
  • 10 级（满级）：消耗 1 个下界之星。
钻石和手机都是物品、无法摆在地面，所以"8 钻石围圈 + 中间放手机"实现为"背包 8 钻石 + 脚下信标代表手机"。

06技术说明

零后端

所有脚本只 import math / time / random / json 与网易 SDK。无 http、socket、requests 等网络调用。炎币是物品，等级/标点/刷新次数存 ExtraData。

Mod SDK（Python）

原 GaoLLC 是 JavaScript（SAPI）组件，账号无 SAPI 权限。已全部用 Python 重写，manifest 只有 type:data。

双保险

准星射线：官方接口失败自动切数学射线。按钮回调：JSON 映射 + Python 回调，0.6 秒去抖。

可重生成

改 templates/ 下脚本与 UI，跑 build_ui.py 再跑 _generate_phone_mod.py，即可重建全部产物与两个包。
